# AI CFO Frontend

Modern multi-page financial dashboard built for the AI CFO Platform.

## Created By

**Smart Solutions Team**

---

## Features

### Dashboard

* Revenue KPI
* Cash Flow KPI
* Expenses KPI
* Profit Margin KPI
* Compliance Status
* Fraud Risk Indicator
* Recent Transactions
* Quick AI Assistant Access

### Analytics Page

* Revenue Trend Chart
* Cash Flow Analysis
* Interactive Charts using Chart.js

### Transactions Page

* View All Transactions
* Pagination Support
* Add Transaction
* Delete Transaction
* Latest Transactions on Dashboard

### Compliance Page

* Compliance Monitoring
* GST Filing Status
* Fraud Risk Monitoring
* Compliance Summary

### AI Assistant Page

* AI CFO Chat Interface
* Financial Query Support
* Real-time Responses

## Configuration

All frontend configuration is stored inside:

```text
config.js
```

Example:

```javascript
const CONFIG = {
    API_BASE_URL: "http://localhost:8000",
    APP_NAME: "AI CFO",
    TEAM_NAME: "Smart Solutions Team"
};
```

---

## Running Frontend

Start backend first:

```bash
cd backend
python app.py
```

Then open:

```text
frontend/index.html
```

in your browser.
